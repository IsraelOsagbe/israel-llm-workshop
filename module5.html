5.1 The Incompressible Navier–Stokes as a DAE

The incompressible equations form a differential-algebraic equation (DAE) of index 2:

∂u/∂t + u·∇u = −∇p + ν∇²u + f (momentum) ∇·u = 0 (constraint)

The pressure p is a Lagrange multiplier enforcing the divergence-free constraint. No time derivative of p exists — pressure is determined instantaneously by the elliptic pressure-Poisson equation.

Helmholtz–Hodge Decomposition (Continuous)

Any vector field w on a domain Ω with boundary ∂Ω decomposes uniquely:

w = u + ∇φ, ∇·u = 0, u·n|_∂Ω = w·n|_∂Ω

The Leray projector P : w ↦ u is orthogonal in L²: P = I − ∇Δ⁻¹∇· (with appropriate BCs). The incompressible NSE is u_t = −P(u·∇u) + νPΔu + Pf.

5.2 Projection Methods (Chorin, Temam, 1967–68)

Split each time step into a prediction (ignoring incompressibility) and a projection (enforcing ∇·u = 0).

Standard Projection (First-Order)

u* = u^n + Δt [ −u^n·∇u^n + ν∇²u^n + f^n ] (predictor) ∇²φ = (1/Δt) ∇·u* (pressure-Poisson) u^{n+1} = u* − Δt ∇φ (projection) p^{n+1} = φ + p^n (pressure update)

Error: u^{n+1} satisfies ∇·u^{n+1} = 0 but u^{n+1} ≠ u(t^{n+1}) + O(Δt) due to boundary condition inconsistency (numerical boundary layer).

Incremental Projection (Second-Order, Goda, 1979)

u* = u^n + Δt [ −(3/2)u^n·∇u^n + (1/2)u^{n-1}·∇u^{n-1} + ν∇²u^{n+1/2} + f^{n+1/2} ] ∇²φ = (1/Δt) ∇·u* u^{n+1} = u* − Δt ∇φ p^{n+1} = p^n + φ − ν∇·u^{n+1} (pressure correction)

Uses implicit viscous term (Crank–Nicolson) and Adams–Bashforth for convection. Achieves second-order accuracy with consistent pressure boundary conditions.

Rotational Form (Timmermans, Minev, Van De Vosse, 1996)

Reformulates the pressure-Poisson equation to enforce the correct Neumann condition at walls:

∇²φ = (1/Δt) ∇·u* − ν∇×(∇×u*)

Eliminates the numerical boundary layer — velocity satisfies no-slip exactly at discrete level. Essential for high-order temporal accuracy at boundaries.

5.3 Pressure-Poisson Equation: Boundary Conditions & Consistency

The pressure-Poisson equation requires a boundary condition. The correct Neumann condition at a solid wall (u = 0) is derived from the momentum equation:

∂p/∂n = n·(ν∇²u + f) = ν n·∇²u (since f=0 at wall)

In discrete form, this becomes a compatibility condition for the Poisson solve. Inconsistent BCs (e.g., ∂p/∂n = 0) introduce an O(1) error in pressure and O(Δt^{1/2}) error in velocity near walls.

Consistent Discretization (Staggered vs. Collocated)

  • Staggered (MAC): Pressure at cell centers, velocity at faces. Natural discrete divergence/gradient are adjoint. Pressure-Poisson is symmetric positive definite. No checkerboard modes.
  • Collocated (Rhie–Chow): All variables at centers. Face velocity interpolated: u_f = u_f^interp − (1/a_p)_f ∇p_f. Requires careful pressure-Poisson discretization to maintain adjoint property.

5.4 Discrete Inf-Sup Stability (LBB Condition)

For a mixed finite element/volume discretization of the saddle-point problem:

Find (u_h, p_h) ∈ V_h × Q_h: a(u_h, v_h) + b(v_h, p_h) = (f, v_h) ∀v_h b(u_h, q_h) = 0 ∀q_h

The Ladyzhenskaya–Babuška–Brezzi (LBB) condition is necessary and sufficient for stability:

inf_{q_h∈Q_h} sup_{v_h∈V_h} b(v_h, q_h) / (||v_h||_V ||q_h||_Q) ≥ β > 0

where b(v, q) = −(∇·v, q). Violations cause spurious pressure modes (checkerboard).

Stabilized Methods (Equal-Order)

For equal-order interpolation (P1–P1, Q1–Q1), add stabilization:

  • PSPG (Pressure-Stabilizing Petrov–Galerkin): Add τ ∇q · (u·∇u + ∇p − νΔu − f)
  • Brezzi–Pitkäranta: Add α h² (∇p, ∇q)
  • Local Projection Stabilization (LPS): Project pressure gradient fluctuations

5.5 Coupled vs. Segregated Solvers

Segregated (SIMPLE Family)

Solve momentum and pressure sequentially:

  1. Solve momentum with current pressure → u*
  2. Solve pressure correction equation: ∇·(A⁻¹∇p') = ∇·u*
  3. Correct: u = u* − A⁻¹∇p', p = p + p'
  4. Under-relax pressure: p^{new} = p^{old} + α p'

SIMPLEC, PISO, SIMPLER vary the correction equation. Slow convergence for high-Re, complex geometries. Easy to implement.

Coupled (Monolithic Newton–Krylov)

Solve the full nonlinear system simultaneously:

[ A B^T ] [ Δu ] = [ R_u ] [ B 0 ] [ Δp ] [ R_p ]

Use physics-based preconditioner (PCD, LSC, AL) with Krylov solver. Quadratic convergence near solution, mesh-independent iterations with good preconditioner. Memory intensive but robust.

All-Speed Preconditioned Coupled Solvers

For variable-density/low-Mach, the system becomes:

[ A B^T C ] [ Δu ] = [ R_u ] [ B 0 0 ] [ Δp ] [ R_p ] [ C^T 0 D ] [ Δρ ] [ R_ρ ]

Extend PCD/LSC to 3×3 block structure. Essential for combustion, atmospheric flows.

5.6 High-Order Temporal Schemes for Incompressible Flow

BDF-k with Projection

Backward Differentiation Formulas (BDF) are A-stable up to k=2, stiffly accurate:

∑_{j=0}^k α_j u^{n+1-j} = Δt [ −P(u·∇u) + νPΔu + Pf ]^{n+1}

Requires solving a coupled system at each step. BDF2 with incremental projection is a good compromise.

IMEX for Incompressible Flow

Treat viscous terms implicitly, convection explicitly:

(I − γΔt νPΔ) u^{n+1} = RHS_explicit + P(γΔt f^{n+1})

Only the Helmholtz operator (I − γνΔ) is inverted per velocity component — much cheaper than full coupled solve.

Spectral Deferred Correction (SDC)

High-order via iterative correction on a Picard integral formulation. Compatible with projection framework. Achieves arbitrary order with low-storage RK-like structure.

Open Boundary Conditions (OBC)

For external flows, use non-reflecting or absorbing BCs:

  • Orlanski-type: ∂φ/∂t + c ∂φ/∂n = 0 for outgoing waves
  • Perfectly Matched Layer (PML): Absorbing layer with complex coordinate stretching
  • Buffer zones / sponge layers: Add damping term −σ(x)(u − u_∞) near boundary

5.8 Fast Pressure Solvers

The pressure-Poisson solve dominates cost in projection methods.

  • FFT (periodic/rectangular): O(N log N), exact diagonalization
  • Geometric Multigrid (structured): O(N), optimal
  • Algebraic Multigrid (unstructured): O(N), robust (BoomerAMG, GAMG)
  • Fast Multipole / H-matrices: O(N) for dense Schur complements
  • Direct sparse (SuperLU, MUMPS, PARDISO): Good for moderate 2D/3D, memory heavy

Pressure Schur Complement Preconditioning

In coupled solvers, the pressure Schur complement S = B A⁻¹ B^T is the bottleneck. PCD/LSC approximate S⁻¹ using AMG on pressure-Poisson and pressure convection-diffusion operators.

Socratic Questions

Question 1: For the standard projection method, show that the discrete velocity u^{n+1} satisfies ∇_h·u^{n+1} = 0 exactly, but the discrete pressure p^{n+1} does not satisfy the correct Neumann condition at walls. Derive the leading-order error in the wall-normal pressure gradient. How does the rotational form fix this?

Question 2: Consider a 1D staggered grid (pressure at cell centers, velocity at faces) and a 1D collocated grid (both at centers). Discretize the divergence and gradient operators. Show that on the staggered grid, the discrete divergence and gradient are negative adjoints, and the pressure-Poisson matrix is an M-matrix. On the collocated grid, show that a checkerboard pressure mode (alternating +1, −1) is in the null space of the discrete Laplacian. How does Rhie–Chow interpolation remove this null space?

Question 3: For the incompressible NSE linearized about a steady state, the Jacobian has the saddle-point structure J = [A B^T; B 0]. Derive the exact block factorization J = [I 0; B A⁻¹ I] [A 0; 0 −S] [I A⁻¹B^T; 0 I] where S = B A⁻¹ B^T. Show that the PCD preconditioner approximates S⁻¹ ≈ (F_p A_p⁻¹ B_p^T)⁻¹ where F_p is the pressure convection-diffusion operator. Why is A_p the pressure mass matrix and not the pressure Laplacian?

Question 4: Design a 2nd-order IMEX scheme for incompressible flow where the viscous term is treated implicitly and convection explicitly. Write the stage equations for ARS(2,2,2). Show that the implicit solve decouples into three independent Helmholtz solves (one per velocity component) plus a pressure-Poisson solve. What is the CFL limit for the explicit convection part?

Question 5: For an external flow simulation (flow past a cylinder), compare the following outflow boundary conditions: (a) do-nothing (traction-free), (b) constant pressure p = 0, (c) convective Orlanski condition. Analyze the reflection coefficient for each using a 1D model problem. Which is most appropriate for (i) steady RANS, (ii) unsteady LES of vortex shedding?
