2.1 Finite Volume Method: Integral Form & Discrete Conservation

The FV method discretizes the integral conservation law directly. For cell i with volume V_i and faces f:

dU_i/dt = −(1/V_i) ∑_f F_f · n_f A_f + S_i

where U_i = (1/V_i) ∫_{V_i} U dV is the cell average. This guarantees exact discrete conservation — fluxes are single-valued at faces: F_f = F(U_L, U_R, n_f). No numerical cancellation errors.

Unstructured Mesh Data Structures

Cell-centered storage: U_i at cell centroids. Face data: centroid x_f, area A_f, normal n_f, neighbor cells (i, j). Reconstruction uses cell neighborhoods N(i) — stencil size grows with order.

Geometric Conservation Law (GCL)

For moving/deforming meshes, the scheme must preserve constant states:

d/dt ∫_{V(t)} 1 dV = ∮_∂V w·n dS

where w is mesh velocity. Violation causes spurious mass/momentum sources — critical for FSI and moving-boundary problems.

2.2 Reconstruction: From Cell Averages to Face Values

High-order accuracy requires reconstructing U(x) within each cell from neighbor averages. For a polynomial of degree k:

U_i(x) = U_i + ∇U_i·(x − x_i) + ½ (x − x_i)^T H_i (x − x_i) + ...

The coefficients (∇U_i, H_i, ...) are determined by a least-squares fit over the stencil N(i):

min_{∇U} ∑_{j∈N(i)} w_{ij} | U_j − U_i − ∇U·(x_j − x_i) |²

where weights w_{ij} typically scale with inverse distance. On highly irregular meshes, weighted least squares (WLSQ) with QR factorization is more robust than Gaussian elimination.

Face Value Evaluation

Left/right states at face f between cells i, j:

U_L = U_i(x_f), U_R = U_j(x_f)

For second-order: U_L = U_i + ∇U_i·(x_f − x_i). This is a linear reconstruction. Higher orders use quadratic or cubic polynomials.

2.3 Slope Limiting: Preventing Oscillations Near Discontinuities

Unlimited high-order reconstruction produces Gibbs oscillations near shocks. Limiters enforce TVB (total variation boundedness) or MP (maximum principle) by reducing to first-order locally.

Barth–Jespersen Limiter (Unstructured)

For each cell i, compute unlimited gradient ∇U_i. Determine limiter φ_i ∈ [0, 1]:

φ_i = min_{j∈N(i)∪{i}} { min( 1, (U_max − U_i) / (U_j^f − U_i) ), min( 1, (U_min − U_i) / (U_j^f − U_i) ) }

where U_j^f = U_i + ∇U_i·(x_j − x_i), and U_max/min are the max/min of U in the neighborhood. The limited gradient is φ_i ∇U_i.

Venkatakrishnan Limiter (Smooth, Differentiable)

Uses a smooth function avoiding the min non-differentiability:

φ(r) = (r² + 2r) / (r² + r + 2), r = (U_max − U_i) / (∇U_i·Δx)

This is C^∞ — crucial for discrete adjoint methods and Newton-Krylov solvers.

WENO Reconstruction on Unstructured Meshes

Weighted Essentially Non-Oscillatory reconstruction combines multiple candidate stencils with nonlinear weights based on smoothness indicators β_k:

ω_k = α_k / ∑ α_l, α_k = d_k / (ε + β_k)²

where d_k are linear weights. WENO achieves optimal order in smooth regions and non-oscillatory at discontinuities without explicit limiting.

2.4 Riemann Solvers: The Numerical Flux Function

The flux F_f at a face is the solution of a 1D Riemann problem with left/right states U_L, U_R and normal n.

Exact Riemann Solver

Solves the Riemann problem exactly (iteratively) — expensive but robust. Standard for Godunov-type methods in research codes.

Approximate Riemann Solvers

SolverWaves ResolvedCostNotes
RoeAll (linearized)MediumRequires entropy fix; fails at vacuum/strong rarefactions

HLLC Flux (Recommended Default)

Resolves three waves: two acoustic (S_L, S_R) and one contact (S_*). The flux is:

F_HLLC = { F_L + S_L(U_*L − U_L) if 0 ≤ S_L { F_*L if S_L ≤ 0 ≤ S_* { F_*R if S_* ≤ 0 ≤ S_R { F_R + S_R(U_*R − U_R) if S_R ≤ 0

with star-region states computed from Rankine–Hugoniot. Wave speed estimates: S_L = min(u_L − c_L, u_* − c_*), S_R = max(u_R + c_R, u_* + c_*), S_* = (p_R − p_L + ρ_L u_L(S_L − u_L) − ρ_R u_R(S_R − u_R)) / (ρ_L(S_L − u_L) − ρ_R(S_R − u_R)).

2.5 High-Order FV on Unstructured Meshes

k-Exact Reconstruction

For order p = k+1, fit a degree-k polynomial to neighbor cell averages. Requires minimum stencil size: 1 (0th), 4 (1st, 2D), 10 (2nd, 2D), 20 (3rd, 2D) — in 3D: 1, 8, 35, 120. Use least squares with larger stencils for robustness.

Flux Quadrature for High-Order

Face flux integral requires quadrature for p ≥ 2:

∫_f F·n dS ≈ ∑_{q=1}^{N_q} w_q F(U(x_q))·n A_f

Use Gaussian quadrature on face: 1 point (1st), 3 points (2nd), 6 points (3rd) for triangles. For polygons, decompose to triangles or use moment-fitted quadrature.

Limiter for High-Order (Hermite WENO, MOOD, etc.)

At p ≥ 3, traditional limiters degrade accuracy. Modern approaches:

  • Hermite WENO (HWENO): Reconstructs both U and ∇U
  • MOOD (Multi-dimensional Optimal Order Detection): A posteriori detection — compute high-order, check admissibility (positivity, TVB), fall back locally
  • ADER (Arbitrary high-order DERivative): One-step space-time predictor + corrector

2.6 Viscous Flux Discretization

Viscous fluxes depend on ∇U at faces. On unstructured meshes, the standard Green–Gauss or least-squares gradient is used. For second-order viscous terms:

(∇U)_f = (∇U_i + ∇U_j)/2 (average) or (∇U)_f = ∇U_i + (∇U_j − ∇U_i) · (x_f − x_i)/|x_j − x_i| (interpolated)

BR2 Scheme (Bassi–Rebay 2)

A compact, high-order consistent viscous flux for DG/FV. Introduces a lifting operator to handle the second derivative. Ensures symmetric positive definite discrete viscous operator — crucial for implicit solvers.

Penalty Methods (SIPG, BR2, NIPG)

For discontinuous Galerkin and high-order FV, interior penalties enforce continuity of fluxes weakly:

F_v* = {F_v} − η [U] (symmetric interior penalty)

where η is the penalty parameter (scales as p²/h). Too small → instability; too large → over-diffusion.

2.7 Source Term Discretization & Well-Balancing

Source terms S(U) (gravity, chemistry, geometry) must be discretized compatibly with fluxes to preserve steady states (e.g., hydrostatic equilibrium).

Well-Balanced Property

A scheme is well-balanced for a steady state U^eq if dU/dt = 0 exactly when U = U^eq. For hydrostatic equilibrium (dp/dz = −ρg):

  • Reconstruct p + ρgz instead of p
  • Or use hydrostatic reconstruction (Audusse et al.)

Essential for atmospheric/oceanic flows, low-Mach combustion, and MHD.

Question 2: Prove that the Barth–Jespersen limiter ensures the reconstructed face values lie within the range of cell averages in the neighborhood. Why does this not guarantee total variation diminishing (TVD) in multiple dimensions? What additional condition is needed?

Question 3: Derive the HLLC star-region pressure p_* and velocity u_* from the Rankine–Hugoniot conditions across the contact wave. Show that the HLLC flux reduces to the exact Riemann solution for an isolated contact discontinuity.

Question 4: For a 3rd-order FV scheme on triangles (p = 3), what is the minimum stencil size for k-exact reconstruction? How many quadrature points are needed on each face? Estimate the operation count per cell per stage relative to a 2nd-order scheme.

Question 5: Consider the shallow water equations with bathymetry b(x): h_t + (hu)_x = 0, (hu)_t + (hu² + ½gh²)_x = −gh b_x. Design a well-balanced reconstruction that exactly preserves the lake-at-rest steady state (u = 0, h + b = const). Prove it preserves this state discretely.
