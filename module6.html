6.1 The Turbulence Closure Problem

Reynolds decomposition: u = ū + u', p = p̄ + p'. Averaging NSE gives:

∂ū/∂t + ū·∇ū = −∇p̄/ρ + ν∇²ū − ∇·(u'u') + f

The Reynolds stress tensor R_{ij} = −u'_i u'_j is unclosed — 6 independent components in 3D. The closure problem is to model R in terms of mean flow quantities.

Exact Transport Equations for Reynolds Stresses

From the fluctuating momentum equation:

D R_{ij}/Dt = P_{ij} + Π_{ij} + D_{ij} − ε_{ij} + D^t_{ij} + D^p_{ij}
  • Production: P_{ij} = −R_{ik} ∂ū_j/∂x_k − R_{jk} ∂ū_i/∂x_k
  • Pressure-strain: Π_{ij} = p'(∂u'_i/∂x_j + ∂u'_j/∂x_i) (redistributes energy among components)
  • Diffusion: D_{ij} = ∂/∂x_k (ν ∂R_{ij}/∂x_k − u'_i u'_j u'_k − δ_{ik} p' u'_j /ρ − δ_{jk} p' u'_i /ρ)
  • Dissipation: ε_{ij} = 2ν ∂u'_i/∂x_k ∂u'_j/∂x_k (isotropic at small scales: ε_{ij} = ⅔ε δ_{ij})

Any RANS model must approximate the unclosed terms (Π, D, ε).

6.2 Eddy Viscosity Models (Boussinesq Hypothesis)

Assume R_{ij} = ν_t (∂ū_i/∂x_j + ∂ū_j/∂x_i) − ⅔ k δ_{ij} where k = ½ R_{ii}.

Zero-Equation (Algebraic) Models

  • Prandtl mixing length: ν_t = l_m² |∂ū/∂y| — simple, attached boundary layers only
  • Baldwin–Lomax: Inner/outer layer algebraic model — legacy, still used in aerospace
  • Cebeci–Smith: Two-layer algebraic model

One-Equation Models

  • Spalart–Allmaras (SA): Transport equation for ν̃ (modified ν_t). 1 equation, robust, widely used in aerospace. Includes trip term, wall-damping, rotation correction (SA-RC).
  • k-equation only: ν_t = C_μ k^{1/2} l with prescribed l — rarely used alone

SST Model Details

Blending function F_1 switches between k–ω (inner) and transformed k–ε (outer):

ν_t = a_1 k / max(a_1 ω, S F_2)

where S = √(2S_{ij}S_{ij}). Includes production limiter (Kato–Launder) and cross-diffusion term in ω-equation. γ-Re_θ transition model extension available.

6.3 Reynolds Stress Models (RSM / Second-Moment Closures)

Solve transport equations for all 6 R_{ij} + ε (7 equations). No Boussinesq hypothesis — captures anisotropy, streamline curvature, rotation effects.

Modeling Unclosed Terms

  • Pressure-strain (Π_{ij}): LRR (Launder–Reece–Rodi), SSG (Speziale–Sarkar–Gatski), quadratic models
  • Dissipation (ε_{ij}): Assumed isotropic: ε_{ij} = ⅔ε δ_{ij} (main limitation)
  • Diffusion: Generalized gradient diffusion hypothesis (GGDH)

Challenges

  • Stiff, coupled system — difficult convergence
  • Wall-reflection terms needed for near-wall behavior
  • Realizability not guaranteed (negative normal stresses)
  • Computational cost: 7× scalar equations vs. 2 for k–ω SST

Use RSM when: swirling flow, strong curvature, rotation, secondary flows, anisotropy matters (e.g., turbomachinery, combustors).

6.4 Scale-Resolving Simulations: LES, DES, WMLES

Large Eddy Simulation (LES)

Filter at scale Δ (grid): ū = G * u. Resolved scales > Δ computed directly; subgrid scales (SGS) modeled.

∂ū/∂t + ∇·(ūū) = −∇p̄/ρ + ν∇²ū − ∇·τ^{SGS} τ^{SGS} = ūū − ū ū

SGS Models

  • Smagorinsky: τ^{SGS}_{ij} − ⅓ τ^{SGS}_{kk} δ_{ij} = −2 (C_s Δ)² |S̄| S̄_{ij} — excessive dissipation, wrong near-wall scaling
  • Dynamic Smagorinsky (Germano): C_s computed from test filter — backscatter possible, needs averaging
  • WALE (Wall-Adapting Local Eddy-viscosity): Correct ν_t ~ y³ near wall — no dynamic procedure needed
  • Vreman: Zero for 2D/laminar, lower dissipation in transition
  • Sigma (Nicoud): Based on singular values of velocity gradient — good for transition

LES Resolution Requirements

Δx⁺ ~ 50–100, Δy⁺_wall ~ 1, Δz⁺ ~ 15–30. Wall-resolved LES at Re_τ = 1000 needs ~10⁹ cells. Cost ~ Re³.

Detached Eddy Simulation (DES)

Hybrid RANS/LES: ν_t = min(ν_t^{RANS}, C_{DES} Δ). RANS near wall, LES in separated regions.

  • SA-DES, SST-DES: Based on underlying RANS model
  • DDES (Delayed DES): Shields boundary layer from premature LES switch
  • IDDES (Improved DDES): Wall-modeling + free-stream protection

Wall-Modeled LES (WMLES)

LES in outer layer, wall model provides shear stress at first grid point (y⁺ ~ 50–200):

  • Equilibrium wall model: Log-law + pressure gradient
  • Non-equilibrium (ODE/PDE) wall model: Solves 1D boundary layer equations on embedded grid
  • Zonal WMLES: RANS near wall, LES outer, blending region

Cost reduction: ~10–100× vs. wall-resolved LES. Standard for high-Re external aerodynamics.

6.5 Wall Models for High-Re Flows

Wall Functions (RANS)

Bridge viscous sublayer: u⁺ = u_τ y⁺ (viscous), u⁺ = 1/κ ln(y⁺) + B (log-law). Standard: y⁺ ∈ [30, 300]. Enhanced wall treatment: two-layer (Wolfshtein) or scalable wall functions.

Key Challenge: Coupling

Wall model provides τ_w to LES; LES provides u_∥, p at matching height. Consistency requires matching location in log-layer and time-accurate coupling for unsteady flows.

6.6 Data-Driven & Machine Learning Closures

Categories

  • Field inversion / Bayesian calibration: Optimize model coefficients (e.g., C_μ, C_ε1) against data
  • Discrepancy modeling: Learn δ = R^{DNS} − R^{RANS} as function of mean flow features
  • Physics-informed neural networks (PINNs): Embed PDE residuals in loss function
  • End-to-end closure: NN maps mean flow → Reynolds stress (Galilean invariant architectures: tensor basis, invariants)
  • SGS models for LES: NN maps resolved strain/rotation → τ^{SGS}

Tensor Basis Neural Networks (TBNN)

Enforce Galilean invariance by expressing R_{ij} as linear combination of tensor basis T^{(k)}_{ij} with scalar coefficients g^{(k)}(λ_1, ..., λ_n) where λ are invariants of S, Ω:

R_{ij} = 2k ∑_{k=1}^{10} g^{(k)}(λ) T^{(k)}_{ij}

10 basis tensors for general 3D flow (Pope, 1975). NN learns g^{(k)} from DNS data.

Challenges

  • Extrapolation beyond training regime
  • Stability when coupled to solver (stiffness, realizability)
  • Data scarcity for high-Re, complex geometries
  • Enforcing physical constraints (realizability, symmetry, Galilean invariance)

6.7 Transition Modeling

RANS models assume fully turbulent. For transitional flows (turbomachinery, low-Re airfoils):

  • γ–Re_θ (Langtry–Menter): Transport equations for intermittency γ and transition momentum thickness Re_θ. Coupled to SST.
  • k–kL–ω (Walters–Cokljat): 3-equation model for laminar kinetic energy.
  • DDES/IDDES with transition: Shielding functions prevent premature LES in laminar regions.
  • LES/DNS of transition: Resolve bypass, natural, separation-induced transition directly.
