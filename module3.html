3.1 Method of Lines & Semi-Discrete Systems

After spatial discretization, we obtain a system of ODEs:

dU/dt = R(U), U ∈ ℝ^N

where R(U) is the spatial residual (flux divergence + sources). The eigenvalues of the Jacobian ∂R/∂U determine the stiffness and stability limits.

Wave Speeds & CFL Condition

For a hyperbolic system with maximum wave speed λ_max on a mesh with characteristic length h:

CFL = λ_max Δt / h ≤ CFL_max

The maximum stable CFL depends on the time integrator and spatial scheme:

Scheme1st-order FV2nd-order FVp-th order DG
Forward Euler1.0~0.5~1/(2p+1)
RK2 (Heun)1.0~0.7~1/(p+1)

RK4~1.4~1.2~2/(p+1)

On unstructured meshes, h is the inscribed circle radius or V/|∂V|.

3.2 Explicit Runge–Kutta Methods

An s-stage RK method:

U^(i) = U^n + Δt ∑_{j=1}^{i-1} a_{ij} R(U^(j)), i = 1..s U^{n+1} = U^n + Δt ∑_{i=1}^s b_i R(U^(i))

Strong Stability Preserving (SSP) RK

SSP methods preserve TVD/monotonicity under a CFL restriction. Optimal SSP coefficients:

  • SSP-RK2: U^(1) = U^n + Δt R(U^n), U^{n+1} = ½U^n + ½(U^(1) + Δt R(U^(1))) — CFL = 1
  • SSP-RK3 (Shu–Osher): 3 stages, CFL = 1 — standard for WENO/DG
  • SSP-RK(5,4): 5 stages, 4th order, CFL ≈ 1.5

Low-Storage RK (Williamson, Kennedy–Carpenter)

For large-scale 3D, memory is critical. 2N storage (vs. sN):

dU = A_i dU + Δt R(U) U = U + B_i dU

Standard 5-stage 4th-order (Carpenter–Kennedy) uses 2N registers.

3.3 Implicit & IMEX Methods for Stiff Problems

Viscous terms, chemistry, low-Mach flow, and high-order spatial discretizations create stiffness: |λ_max| ≫ |λ_min|. Explicit methods require tiny Δt.

IMEX Runge–Kutta (Additive RK)

Split residual: R(U) = R_exp(U) + R_imp(U) (e.g., convective explicit, viscous implicit):

U^(i) = U^n + Δt ∑_{j=1}^{i-1} ã_{ij} R_exp(U^(j)) + Δt ∑_{j=1}^{i} a_{ij} R_imp(U^(j))

Explicit tableau Ã (strictly lower triangular), implicit tableau A (lower triangular). Diagonally implicit (DIRK) allows stage-by-stage solves.

Fully Implicit (Backward Euler, BDF, SDIRK)

For steady problems or extreme stiffness, fully implicit methods allow arbitrarily large Δt. Require solving nonlinear systems (Newton–Krylov) each step.

3.4 Linear Stability Analysis

Apply method to u' = λ u (λ ∈ ℂ). The amplification factor G(z) where z = λΔt:

  • Forward Euler: G(z) = 1 + z
  • RK4: G(z) = 1 + z + z²/2 + z³/6 + z⁴/24
  • Backward Euler: G(z) = 1/(1 − z)
  • SDIRK(2): G(z) = (1 + (1−γ)z) / (1 − γz)²

Stability Region

{z ∈ ℂ : |G(z)| ≤ 1}. Key properties:

  • A-stable: Contains left half-plane (Re(z) ≤ 0)
  • L-stable: A-stable + |G(z)| → 0 as Re(z) → −∞
  • Stiffly accurate: G(∞) = 0 — essential for DAE/index-2 systems (incompressible flow)

Explicit RK: finite stability region on negative real axis. Implicit RK/SDIRK: A- or L-stable.

3.5 Exponential Integrators & Rosenbrock Methods

For problems with known linear part (e.g., viscous terms, acoustic waves), exponential integrators solve the linear part exactly:

U^{n+1} = e^{Δt L} U^n + Δt φ_1(Δt L) N(U^n) + ...

where R(U) = L U + N(U), L linear (constant or frozen), φ_1(z) = (e^z − 1)/z. Advantage: No CFL limit from linear part; Challenge: Computing e^{Δt L} or φ-functions for large sparse L (Krylov, scaling-and-squaring).

Rosenbrock Methods (Linearly Implicit)

Approximate the Jacobian once per step, solve linear systems with (I − γΔt J):

(I − γΔt J) K_i = R(U^n + ∑_{j< i} α_{ij} K_j) + Δt J ∑_{j< i} γ_{ij} K_j

No nonlinear solves per stage — only linear. Order 2–4 available (ROS2, ROS3P, ROS4). Popular for reactive flow and MHD.

3.6 Time Step Control & Adaptivity

For unsteady simulations, Δt should be adaptive based on:

  • CFL condition: Δt ≤ CFL_max · h / λ_max
  • Local truncation error: Embedded pairs (e.g., RK5(4)) give error estimate e = U^{n+1}_{5th} − U^{n+1}_{4th}
  • Controller: Δt_{new} = Δt_{old} · (TOL / ||e||)^{1/(p+1)} · safety_factor

Dual Time Stepping (Steady Problems)

For steady-state using implicit methods, introduce pseudo-time τ:

∂U/∂τ + ∂U/∂t = R(U)

Discretize physical time implicitly (BDF2), pseudo-time explicitly (RK). Iterate pseudo-time to convergence at each physical step. For pure steady: ∂U/∂τ = R(U) — pseudo-transient continuation.

3.7 Splitting Errors & Order Reduction

IMEX and splitting methods suffer from order reduction when applied to stiff PDEs. The classical order is not achieved due to boundary layers in time (stiff transients).

Mitigation Strategies

  • Use stiffly accurate methods (SDIRK, BDF)
  • Increase stage order (e.g., ARS(3,4,3) has stage order 2)
  • Use exponential integrators for the linear stiff part
  • For low-Mach: preconditioning or all-speed IMEX (Dimarco–Pareschi)

Question 3: In the low-Mach limit (Ma → 0), the acoustic wave speeds scale as 1/Ma while convective scales are O(1). Analyze the stiffness ratio for an explicit method. Design an IMEX splitting that treats acoustic terms implicitly and convective terms explicitly. What is the resulting CFL limit? Does it depend on Ma?

Question 4: For the linear advection-diffusion equation u_t + a u_x = ν u_xx with periodic BCs, the spatial discretization gives du/dt = L u where L is a circulant matrix. Derive the exact exponential integrator solution for one time step. How would you approximate φ_1(Δt L) for a general unstructured mesh using Krylov methods? What is the computational cost per step vs. implicit RK?

Question 5: In dual time stepping for steady compressible flow, the pseudo-time step is often controlled by a local CFL number that varies per cell. Derive the optimal local time step for a cell based on its spectral radius. Why does local time stepping accelerate convergence to steady state but destroy time-accuracy?
