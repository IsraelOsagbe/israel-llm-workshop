7.1 Verification vs. Validation: Definitions & Hierarchy

Verification: "Are we solving the equations right?"

Code Verification: Does the code correctly implement the intended mathematical model? Methods: Method of Manufactured Solutions (MMS), order-of-accuracy tests, symmetry/invariance tests.

Solution Verification: For a specific simulation, estimate the numerical errors (discretization, iteration, round-off). Quantify uncertainty in the computed solution.

Validation: "Are we solving the right equations?"

Compare simulation results to independent experimental data for the same physical configuration. Quantify the difference relative to combined uncertainties (numerical + experimental).

V&V Hierarchy (AIAA G-077)

  1. Level 0: Code verification (MMS, analytic solutions)
  2. Level 1: Canonical flows (flat plate BL, cylinder, backward-facing step, Taylor–Green vortex)
  3. Level 2: Component flows (airfoil, nozzle, diffuser, combustor sector)
  4. Level 3: System flows (full aircraft, engine, vehicle)

Validate at the lowest level possible before trusting higher-level predictions.

7.2 Code Verification: Method of Manufactured Solutions (MMS)

Choose an arbitrary smooth manufactured solution U_m(x,t) that satisfies BCs. Substitute into the PDE to obtain a manufactured source term S_m:

S_m = ∂U_m/∂t + ∇·F(U_m) − ∇·F_v(U_m, ∇U_m)

Solve the modified PDE with source S_m. The exact solution is U_m. Compute error E = U_h − U_m and verify observed order p_obs = log(||E_h||/||E_{2h}||) / log(2) matches theoretical order.

MMS Best Practices

  • Use trigonometric/hyperbolic functions (non-polynomial) to exercise all derivative terms
  • Manufacture solution in primitive variables, convert to conserved for source term
  • Test on irregular/unstructured meshes (not just Cartesian)
  • Test boundary condition implementation separately (manufactured solution must satisfy BCs)
  • Test source term integration (geometric source, chemistry, radiation)

Order-of-Accuracy Test Protocol

  1. Generate mesh sequence: h, h/2, h/4, ... (uniform refinement)
  2. Compute error norms: L_1, L_2, L_∞
  3. Fit log(||E||) = log(C) + p log(h) via linear regression
  4. Accept if |p_obs − p_theory| < 0.1 for fine meshes

7.3 Solution Verification: Discretization Error Estimation

Richardson Extrapolation (Single Grid)

Assume U_h = U_exact + C h^p + O(h^{p+1}). On three grids h, h/r, h/r² (r ≥ 2):

U_exact ≈ U_h + (U_h − U_{h/r}) / (r^p − 1) Error estimate: E_h ≈ (U_h − U_{h/r}) / (r^p − 1)

Requires asymptotic range (mesh fine enough that higher-order terms negligible). Verify with p_obs from grid convergence study.

Grid Convergence Index (GCI) — Roache (1994, 1997)

Standardized error band for engineering use:

GCI = F_s |U_h − U_{h/r}| / (r^p − 1)

where F_s = 1.25 (factor of safety for 3+ grids) or 3.0 (2 grids only). GCI represents a 95% confidence interval on the discretization error.

Grid Convergence Study Requirements (ASME V&V 20)

  • Minimum 3 significantly different grids (refinement ratio r ≥ 1.3, preferably 2)
  • Mesh refinement must be systematic (same topology, uniform scaling)
  • Monitor p_obs — must approach theoretical p on finest grids
  • If p_obs degrades: not in asymptotic range, or coding error, or singularities
  • Report U_exact, E_h, GCI, p_obs for each QoI

Generalized Richardson Extrapolation (Non-Asymptotic)

If not in asymptotic range, use Courant's method or least-squares fit of U_h = U_exact + C h^p over all grids. More robust but less theoretically grounded.

7.4 Iteration & Round-off Error

Iteration Convergence Criteria

  • Residual reduction: 3–4 orders of magnitude (steady RANS)
  • QoI stabilization: Drag, lift, pressure drop change < 0.1% over 100 iterations
  • Global balances: Mass, momentum, energy conserved to machine precision

Iteration Error Estimation

For iterative linear solvers (Krylov): ||r_k|| / ||r_0|| < ε. For nonlinear: ||F(U^k)|| < ε ||F(U^0)||. The iteration error in QoI is bounded by the residual tolerance times the condition number of the QoI functional.

Round-off Error

Double precision: ε_mach ≈ 2×10⁻¹⁶. Accumulated error in SpMV: O(ε_mach N_nz). For N=10⁷, N_nz=10⁸ → ~10⁻⁸ relative error. Usually negligible vs. discretization error, but can limit achievable residual in tight-tolerance solves.

7.5 Model-Form Uncertainty & Validation Metrics

Validation Comparison Error

For a QoI Q: E = Q_{sim} − Q_{exp}. Total uncertainty:

U_{total} = √(U_{num}² + U_{exp}² + U_{input}² + U_{model}²)

Validation passes if |E| ≤ U_{total} (at 95% confidence).

Model-Form Uncertainty (The Hard Part)

Turbulence model inadequacy is the dominant uncertainty in most RANS simulations. Approaches:

  • Elicitation: Expert judgment (structured, documented)
  • Multiple models: Spread of predictions across models (SST, SA, RSM, etc.)
  • Bayesian model averaging: Weight models by evidence
  • Discrepancy modeling (Kennedy–O'Hagan): y(x) = η(x,θ) + δ(x) + ε where η is simulation, δ is model discrepancy (GP), ε is observation noise

7.6 Input Uncertainty Propagation

Sources: BCs (inlet profile, turbulence intensity), geometry tolerances, material properties, fluid properties.

Propagation Methods

  • Local sensitivity: dQ/dθ_i via adjoint or finite differences — cheap, linear only
  • Monte Carlo: Sample inputs, run simulation — expensive, non-intrusive
  • Polynomial Chaos Expansion (PCE): Q(ξ) = ∑ c_α Ψ_α(ξ) — spectral convergence for smooth responses
  • Stochastic Collocation: Sparse grid quadrature (Smolyak) — efficient for moderate dimensions
  • Multi-fidelity: Combine low-fidelity (many samples) + high-fidelity (few samples) via control variates or co-kriging

Global Sensitivity Analysis (Sobol Indices)

Decompose output variance: Var[Q] = ∑ V_i + ∑ V_{ij} + .... First-order index S_i = V_i / Var[Q] measures main effect of input i. Total-order index S_{Ti} includes all interactions.

7.7 Bayesian Calibration of Model Parameters

Calibrate turbulence model coefficients θ against experimental data D:

p(θ|D) ∝ p(D|θ) p(θ)

where p(D|θ) = ∫ p(D|η,θ) p(η|θ) dη is the marginal likelihood. The forward model η(θ) is the CFD simulation.

Challenges

  • Forward model is expensive (hours/days per sample)
  • High-dimensional parameter space (5–20 coefficients)
  • Model discrepancy δ(x) must be included to avoid overfitting
  • MCMC requires 10⁴–10⁵ samples — use surrogates (GP, PCE, NN)

Surrogate-Based Calibration

  1. Build Gaussian Process (GP) or PCE surrogate of Q(θ) from ~50–200 CFD runs
  2. Run MCMC on surrogate (millions of samples, seconds each)
  3. Validate posterior predictions with additional CFD runs

7.8 Practical V&V Workflow for a CFD Project

Phase 1: Code Verification (Before Production Runs)

  1. Run MMS on all physics modules (inviscid, viscous, heat transfer, chemistry, etc.)
  2. Verify order-of-accuracy on uniform and stretched meshes
  3. Test conservation properties (mass, momentum, energy) to machine precision
  4. Test symmetry/invariance (grid rotation, Galilean boost)

Phase 2: Solution Verification (Per Simulation)

  1. Generate 3+ mesh sequence (coarse/medium/fine)
  2. Run all to same convergence criteria
  3. Compute QoI on each grid, perform Richardson extrapolation
  4. Report U_exact, GCI, p_obs for each QoI
  5. If p_obs < theoretical: investigate (singularity, BC error, limiter activation)

Phase 3: Validation (If Experimental Data Exists)

  1. Identify validation dataset (same geometry, Re, Ma, BCs)
  2. Quantify experimental uncertainty U_exp (Type A + Type B)
  3. Compare QoI: compute E, U_total
  4. If |E| > U_total: diagnose (model-form, input uncertainty, experimental error)
  5. Document validation domain (range of conditions where validated)

Phase 4: UQ for Predictive Simulations

  1. Identify uncertain inputs (BCs, geometry, properties)
  2. Propagate uncertainties (local sensitivity → PCE/MC as needed)
  3. Quantify model-form uncertainty (multiple models, discrepancy)
  4. Report prediction interval: Q_pred ± U_total

Derive the manufactured source terms S_m for the continuity, x-momentum, y-momentum, and energy equations. Show that the source terms are non-zero and exercise all flux Jacobian entries.

Question 2: A grid convergence study for drag coefficient yields: C_d(1M) = 0.0321, C_d(4M) = 0.0308, C_d(16M) = 0.0305. Assuming 2nd-order spatial accuracy and refinement ratio r = 2 (since 4M/1M = 4 = r² in 2D), compute the Richardson extrapolated C_d_exact, the estimated error on the 4M grid, and the GCI (95% confidence) for the 4M grid. Is the solution in the asymptotic range?

Question 3: You have RANS predictions for a separated flow using three models: SST (C_d = 0.042), SA (C_d = 0.038), RSM (C_d = 0.045). Experimental value: 0.040 ± 0.002. The numerical uncertainty on the medium grid is ±0.001. Quantify the model-form uncertainty using (a) the spread of model predictions, (b) the Kennedy–O'Hagan discrepancy approach. Which model(s) pass validation? What does this tell you about the reliability of RANS for this flow?

Question 4: In Bayesian calibration of the SST model coefficients θ = (β*, a_1, κ, ...) against flat-plate skin friction data, the likelihood is p(D|θ) = N(D; η(θ), Σ_exp + Σ_num). Explain why model discrepancy must be included in the covariance. If you omit δ(x), what happens to the posterior as the number of data points increases? How would you parameterize δ(x) as a Gaussian Process?

Question 5: For a transonic airfoil simulation, the uncertain inputs are: Mach number (Ma = 0.75 ± 0.01), angle of attack (α = 1.25° ± 0.05°), turbulence intensity (TI = 0.1% ± 0.05%), wall temperature (T_w = 300 K ± 5 K). Design a sparse grid stochastic collocation study using Smolyak quadrature with level 3. How many CFD runs are needed? If each run takes 2 hours, what is the total compute time?
