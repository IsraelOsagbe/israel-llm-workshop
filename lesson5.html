The End-to-End Process

Running a CFD simulation is not "meshing and hitting run." A professional workflow has distinct phases, each with decisions that affect the final result:

  1. Problem Definition — What question are you answering?
  2. Pre-processing — Geometry, mesh, physics setup, boundary conditions
  3. Solving — Solver settings, initialization, monitoring, convergence
  4. Post-processing — Visualization, quantitative extraction, uncertainty assessment
  5. Verification & Validation (V&V) — Is the math right? Is the physics right?

Skipping or rushing any phase is the most common source of wrong answers.

Phase 1: Problem Definition

Before opening a mesher, write down:

  • Quantity of interest (QoI): Drag coefficient? Pressure drop? Temperature distribution? Mixing efficiency?
  • Required accuracy: ±1%? ±10%? Order of magnitude?
  • Flow regime: Incompressible/compressible? Laminar/turbulent? Steady/unsteady? Single/multi-phase?
  • Resources: Compute budget (core-hours), wall-clock deadline, license constraints
  • Comparison data: Experimental data? Previous simulations? Analytical solution?

Example: "Predict the drag coefficient of a NACA 0012 airfoil at Re = 6×10⁶, M = 0.15, α = 1.25° to within ±5% of the NASA experimental data, using ≤ 5000 core-hours."

Phase 2: Pre-processing

Geometry Preparation

  • Clean CAD: remove fillets/chamfers smaller than mesh resolution, fix gaps, simplify non-critical features
  • Extract fluid volume (not the solid!)
  • Create named selections for boundaries: inlet, outlet, walls, symmetry, periodic

Mesh Generation — The Most Time-Consuming Step

  • Boundary layer resolution: First cell height set by target y⁺ (≈1 for wall-resolved LES, 30–300 for wall-function RANS)
  • Growth rate: ≤ 1.2 in boundary layer, ≤ 1.3 elsewhere
  • Orthogonality & skewness: Check mesh quality metrics; bad cells kill convergence and accuracy
  • Refinement zones: Wake, shear layers, shocks, separation regions
  • Mesh independence study: Run at least 3 mesh densities (coarse/medium/fine), plot QoI vs. cell count — it should plateau

Physics Setup

  • Governing equations: RANS, LES, DNS, potential flow, Euler?
  • Turbulence model: k–ω SST (default), k–ε, SST-LES, WMLES, etc.
  • Fluid properties: constant or variable? Ideal gas? Real gas table?
  • Reference values: for non-dimensionalizing outputs (drag coeff, etc.)

Boundary Conditions — Garbage In, Garbage Out

  • Inlet: Velocity profile (uniform, parabolic, measured), turbulence intensity & length scale (or k, ω, ε)
  • Outlet: Pressure outlet (most robust), outflow, or far-field. Avoid fixed velocity at outlet.
  • Walls: No-slip (default), slip (symmetry), moving wall, rough wall
  • Symmetry/Periodic: Only if flow physics truly symmetric/periodic

Phase 3: Solving

Initialization

  • Uniform flow (simple, may diverge for separated flows)
  • Potential flow solution (fast, good for attached flows)
  • Restart from a similar converged case (best for parametric studies)

Solver Settings

  • Steady vs. unsteady: RANS is usually steady; LES must be unsteady
  • Time step (unsteady): CFL ≈ 1–5 for LES, up to 50–100 for steady with local time stepping
  • Under-relaxation: Critical for steady segregated solvers (pressure 0.3–0.7, momentum 0.5–0.9)
  • Discretization schemes: 2nd-order upwind for momentum, PRESTO! or 2nd-order for pressure

Monitoring Convergence

Watch residuals AND physical monitors (drag, lift, pressure drop, mass flow):

  • Residuals: 3–4 orders of magnitude drop, then flat
  • Monitors: Plateau to constant value (oscillate for unsteady)
  • Mass imbalance: < 0.1% of inlet mass flow

If residuals stall but monitors are flat → solution may be converged. If monitors drift → not converged.

Phase 4: Post-processing

Visualization

  • Contours: Pressure, velocity magnitude, Mach number, temperature
  • Vectors/Streamlines: Flow direction, separation, recirculation
  • Wall quantities: y⁺, wall shear stress, pressure coefficient Cp
  • Cut planes / isosurfaces: Vorticity (Q-criterion, λ₂), total pressure loss

Quantitative Extraction

  • Force reports: Drag, lift, moment coefficients (integrate pressure + shear)
  • Surface integrals: Average pressure, temperature, heat flux
  • Mass flow verification: Inlet = outlet + leakage
  • Profiles: Velocity/temperature at key stations for comparison with experiment

Uncertainty Quantification (UQ)

Every CFD result has uncertainty from:

  • Discretization error: Mesh convergence study (Richardson extrapolation gives error estimate)
  • Iteration error: Residual level at stop
  • Model-form error: Turbulence model inadequacy (hard to quantify)
  • Input uncertainty: Boundary conditions, geometry tolerances, material properties

Phase 5: Verification & Validation (V&V)

Verification: "Are we solving the equations right?"

  • Code verification: Method of manufactured solutions, order-of-accuracy tests (done by code developers)
  • Solution verification: Mesh convergence, iteration convergence, round-off checks (done by YOU for each simulation)

Validation: "Are we solving the right equations?"

  • Compare simulation results to independent experimental data for the same configuration
  • Quantify the difference: is it within combined numerical + experimental uncertainty?
  • If no experimental data exists → it's not validation, it's "calibration" or "faith"

The V&V Hierarchy

  1. Canonical cases (flat plate boundary layer, cylinder in crossflow, backward-facing step)
  2. Component-level experiments (airfoil, nozzle, diffuser)
  3. Full-system experiments (complete aircraft, engine, vehicle)

Validate at the lowest level possible before trusting full-system predictions.

Common Pitfalls for Beginners

PitfallSymptomFix
Bad mesh near wallWrong skin friction, separation predictionCheck y⁺, add prism layers, mesh independence study
Wrong turbulence modelSeparation missing/predicted wrong, wrong pressure recoveryTry SST, compare models, check literature for similar flows
Outlet too closeBackflow, pressure reflection, wrong forcesExtend domain, use pressure far-field
Unsteady run as steadyResiduals oscillate, monitors don't convergeSwitch to unsteady, or accept time-averaged unsteady
No mesh independenceResult changes with mesh, no error estimateRun 3+ meshes, plot QoI vs. 1/N
Trusting color plotsPretty pictures, wrong numbersAlways extract quantitative data, verify balances

Your First CFD Project Checklist

Before considering a simulation "done":

  • [ ] Problem defined with QoI and target accuracy
  • [ ] Geometry cleaned, fluid volume extracted
  • [ ] Mesh with boundary layers (y⁺ checked), quality metrics OK
  • [ ] Mesh independence study completed (3+ meshes)
  • [ ] Physics models justified for this flow regime
  • [ ] Boundary conditions physically consistent, far enough
  • [ ] Initialization reasonable, solver settings standard
  • [ ] Residuals dropped 3+ orders, monitors flat, mass balance <0.1%
  • [ ] Quantitative results extracted (forces, profiles, integrals)
  • [ ] Compared to experimental/analytical data if available
  • [ ] Discretization error estimated (Richardson extrapolation)
  • [ ] Limitations documented (model assumptions, input uncertainties)

Check Your Understanding

Question 1: You run a simulation on three meshes: 1M, 4M, and 16M cells. The drag coefficient is 0.0321, 0.0308, and 0.0305 respectively. Estimate the "exact" (zero mesh size) drag coefficient using Richardson extrapolation assuming 2nd-order spatial accuracy. What is the estimated discretization error on the 4M mesh?

Question 2: A student sets up an external aerodynamics simulation (car at highway speed) with a velocity inlet 2 car-lengths upstream and a pressure outlet 3 car-lengths downstream. The residuals converge but the drag coefficient is 15% higher than wind-tunnel data. Name three specific things about the boundary conditions or domain size that could cause this discrepancy.

Question 3: Explain the difference between verification and validation in CFD. Your simulation of a new heat exchanger design shows a pressure drop of 850 Pa. The only experimental data available is for a similar (but not identical) heat exchanger at a different Reynolds number, showing 780 Pa. Is comparing your 850 Pa to their 780 Pa an act of verification or validation? What would you need to do to make it the other one?
