4.1 Linear Systems in CFD: Structure & Properties

Implicit time stepping, Newton linearization, and steady-state solves all require solving Ax = b where A ∈ ℝ^{N×N} is large, sparse, and structured.

Spectral Properties & Conditioning

For a model Poisson problem on uniform mesh: κ(A) ~ O(h⁻²). For advection-dominated: κ(A) ~ O(h⁻¹). For high-Re NS: κ(A) ~ O(Re·h⁻²). Condition number grows with refinement — necessitates preconditioning.

4.2 Krylov Subspace Methods: Theory

Given Ax = b, Krylov methods build solutions in K_m(A, r_0) = span{r_0, A r_0, ..., A^{m-1} r_0}.

Conjugate Gradient (CG) — SPD Only

Minimizes ||x − x*||_A over K_m. Convergence bound:

||x_m − x*||_A ≤ 2 ( (√κ − 1)/(√κ + 1) )^m ||x_0 − x*||_A

CG converges in at most N steps (exact arithmetic). Requires only SpMV and dot products.

GMRES — General Nonsymmetric

Minimizes ||b − A x_m||_2 over K_m. Arnoldi process builds orthonormal basis V_m:

A V_m = V_{m+1} H_m

Cost: O(mN) storage, O(m²N) work per restart. Restarted GMRES(m) limits memory but may stall.

BiCGSTAB, TFQMR, IDR(s)

Short-recurrence methods for nonsymmetric systems. BiCGSTAB: 2 SpMV/iter, often faster than GMRES but can break down. IDR(s): robust, tunable dimension s.

Convergence Theory (Elman, Greenbaum, etc.)

GMRES convergence depends on field of values F(A) = {x*Ax / x*x} and pseudospectra. For normal matrices, depends on eigenvalue clustering. For non-normal, depends on departure from normality.

4.3 Preconditioning: Transforming the Spectrum

Left preconditioning: M⁻¹Ax = M⁻¹b. Right: AM⁻¹y = b, x = M⁻¹y. Goal: cluster eigenvalues of M⁻¹A near 1.

Algebraic Multigrid (AMG) — The Gold Standard

AMG builds a hierarchy of coarser matrices A_0, A_1, ..., A_L purely algebraically:

  1. Coarsening: Select C-points (coarse) and F-points (fine) via maximal independent set or compatible relaxation
  2. Interpolation (Prolongation): P_k : ℝ^{n_{k+1}} → ℝ^{n_k} — smooth error interpolation
  3. Restriction: R_k = P_k^T (Galerkin) or transpose
  4. Coarse operator: A_{k+1} = R_k A_k P_k

V-cycle: smooth → restrict → coarse solve → prolongate → smooth. Mesh-independent convergence for elliptic problems.

AMG for Systems (Block AMG, Unknown-Based)

For Navier–Stokes, unknown-based AMG (e.g., BoomerAMG in hypre) treats each variable separately. Block AMG (e.g., ML in Trilinos) preserves block structure. Auxiliary-space AMG (AMS, ADS) for H(curl)/H(div) problems (MHD, FEM).

4.4 Physics-Based Preconditioning for Navier–Stokes

Generic algebraic preconditioners ignore physics. Physics-based preconditioners exploit block structure.

Block Factorization of the Newton Matrix

For compressible NS (5 equations in 3D), the Jacobian has 5×5 blocks per cell-face. For incompressible (staggered/collocated):

J = [ A B^T ] [ B 0 ]

where A ≈ momentum (velocity block), B ≈ discrete divergence, B^T ≈ gradient. The Schur complement is S = −B A⁻¹ B^T ≈ pressure-Poisson.

Pressure-Convection-Diffusion (PCD) Preconditioner

For incompressible flow (Kay, Loghin, Wathen, 2002):

P_PCD⁻¹ = [ A⁻¹ 0 ] [ I −B^T ] [ I 0 ] [ 0 (F_p A_p⁻¹ B_p^T)⁻¹ ] [ 0 I ] [ 0 −B ]

where A_p is pressure mass matrix, F_p is pressure convection-diffusion operator. Requires only AMG on A and AMG on pressure-Poisson.

Least-Squares Commutator (LSC) Preconditioner

Approximates the Schur complement via S ≈ B A⁻¹ B^T. Computes A⁻¹ approximately by solving a least-squares problem on the pressure space. Robust for high-Re, complex geometries.

Augmented Lagrangian Preconditioning

Modify the saddle-point system:

J_γ = [ A + γ B^T W⁻¹ B B^T ] [ B 0 ]

For large γ, the Schur complement becomes S_γ ≈ (1/γ) W (mass matrix) — easily invertible with AMG. Trade-off: inner solves for A + γ B^T W⁻¹ B become harder.

4.5 Preconditioning for Compressible Flow

Block Jacobi / Block ILU with Physics Ordering

Order variables as (ρ, ρu, ρv, ρw, ρE) per cell. Block Jacobi uses 5×5 block inverses. Block ILU(0) with this ordering captures inter-equation coupling exactly at the block level.

Low-Mach Preconditioning (Turkel, Weiss–Smith)

At low Ma, the Euler preconditioning matrix Γ modifies the time derivative:

Γ ∂U/∂t + ∇·F = 0, Γ = diag(1, 1, 1, 1, 1/Ma²) (simplified)

This clusters eigenvalues, removing the 1/Ma stiffness. For implicit solves, use Γ in the Jacobian: J = Γ/Δt + ∂R/∂U.

All-Speed Preconditioners

Combine low-Mach preconditioning with IMEX splitting (Dimarco–Pareschi, 2017). Implicit part: acoustic + pressure; Explicit: convection. Preconditioner inverts the acoustic subsystem approximately.

4.6 Parallel Scalability & Implementation

Domain Decomposition

  • Partitioning: ParMETIS, PT-Scotch, Zoltan — minimize edge cut, balance load
  • Ghost layers: 1 layer for 2nd-order, k layers for k-th order
  • Communication: MPI_Isend/Irecv for SpMV, overlap with computation

Scalable Preconditioners

  • BoomerAMG (hypre): Algebraic multigrid, scales to 1M+ cores
  • ML/GMG (Trilinos): Geometric/Algebraic MG, flexible smoothing
  • PETSc PCFieldSplit: Block preconditioning framework (PCD, LSC, FBP)
  • GAMG (PETSc): Aggregation-based AMG

GPU Acceleration

  • SpMV: cuSPARSE, custom kernels (CSR, ELLPACK, SELL-C-σ)
  • Preconditioners: Block Jacobi (trivial), ILU (hard), AMG (hard — use AMGX or hypre GPU)
  • Krylov: cuSPARSE GEMV + custom kernels for dot products, AXPY

4.7 Newton–Krylov Methods for Nonlinear Systems

For steady problems or implicit time stepping, solve F(U) = 0 via Newton:

J(U^k) ΔU^k = −F(U^k), U^{k+1} = U^k + α ΔU^k

where J = ∂F/∂U. The linear solve is inexact: ||J ΔU + F|| ≤ η_k ||F||.

Inexact Newton & Forcing Terms

η_k = min(η_max, ||F(U^k)||^p) (Eisenstat–Walker). Prevents oversolving early Newton steps.

Jacobian-Free Newton–Krylov (JFNK)

Matrix-free: J v ≈ (F(U + εv) − F(U))/ε. No Jacobian storage; requires only residual evaluations. Preconditioning is critical — use approximate Jacobian (lagged, simplified physics) for M⁻¹.

Globalization: Line Search & Trust Region

Backtracking line search on ||F(U)||. Trust region: ||ΔU|| ≤ Δ. Essential for robustness on difficult problems (transonic, separated flows).

Socratic Questions

Question 1: Prove that for a symmetric positive definite matrix A, the CG method minimizes the A-norm of the error over the Krylov subspace. Derive the convergence bound ||e_m||_A ≤ 2((√κ−1)/(√κ+1))^m ||e_0||_A. What does this imply about the number of iterations needed to reduce the error by a factor of 10⁻⁶ for κ = 10⁴?

Question 2: In classical AMG (Ruge–Stüben), the coarse grid is chosen so that each fine point (F-point) is strongly connected to at least one coarse point (C-point). Define strong connection in terms of matrix entries. For a 5-point Laplacian on a uniform grid, show that standard coarsening yields a grid spacing of 2h on the coarse level.

Question 3: For the incompressible Navier–Stokes saddle-point system, derive the exact block factorization of the Jacobian. Show that the Schur complement S = −B A⁻¹ B^T is spectrally equivalent to the pressure-Poisson operator. How does the PCD preconditioner approximate A⁻¹ and why is the pressure convection-diffusion operator F_p needed?

Question 4: The preconditioning matrix Γ = diag(1, 1, 1, 1, 1/Ma²) for the Euler equations modifies the time derivative. Compute the eigenvalues of Γ⁻¹ A_n where A_n = ∂F/∂U · n is the flux Jacobian in direction n. Show that the preconditioned system has eigenvalues that remain O(1) as Ma → 0, whereas the unpreconditioned system has eigenvalues O(1/Ma).

Question 5: In Jacobian-Free Newton–Krylov (JFNK), the matrix-vector product Jv is approximated by finite differences: Jv ≈ (F(U+εv)−F(U))/ε. Analyze the optimal choice of ε balancing truncation error (O(ε)) and roundoff error (O(ε_mach/ε)). Why is a good preconditioner more critical in JFNK than in standard Newton–Krylov with exact Jacobian?
